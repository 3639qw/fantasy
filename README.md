## 🎮 게임 소개

> 현대의 농사 시뮬레이션은 ‘경영 요소’에 충실하지만, 전투와 탐험 요소가 부족합니다.  
> 반대로 샌드박스 전투 게임은 전투 중심이지만, 자원 관리나 성장 시스템이 미흡하죠.  
> **Hero’s Harvest**는 이 두 장르의 장점을 결합해, **농사 + 전투 + 탐험 + 성장**이 유기적으로 연결된 새로운 형태의 **2D 픽셀 액션 게임**입니다.

---

## 🧑‍🌾 핵심 시스템

### 🌱 농사 시스템
> “Hero’s Harvest” 이름 그대로, 농사는 게임의 핵심입니다.

- **성장 주기 시스템**  
  작물은 게임 내 시간에 따라 `씨앗 → 새싹 → 성장 → 수확`의 단계를 거칩니다.
- **수확물 활용**  
  단순 판매용이 아닌 **포션 제작, 장비 강화** 등 전투와 직접 연결됩니다.

---

### ⚔️ 전투 시스템
> 단순한 클릭 전투가 아닌, 회피와 스킬을 활용한 액션 중심 전투!

- **FSM 기반 AI 제어**  
  몬스터는 `순찰 → 탐색 → 공격 → 회피` 등의 행동을 **Finite State Machine** 구조로 제어
- **다양한 무기 & 마법 스킬**  
  근접/원거리/마법 등 여러 전투 스타일을 선택 가능
- **지역별 특성 몬스터**  
  속성, 공격 패턴, 난이도가 달라 전투 전략성이 강화됨

### 🪓 수집 및 제작 시스템
- **자원 채집** : 필드, 던전, 보스 지역에서 다양한 재료 수집
- **아이템 제작** :
  - `철 + 나무` → **철 도끼**
  - `약초 + 물` → **회복 포션**
- **탐험 연동** :  
  희귀 자원은 특정 지역에서만 획득 가능 → 자연스러운 전투·탐험 유도

## 🧭 기술 구성

### 🕹 Unity + NavMesh Plus
- Unity 내비게이션 시스템을 확장한 **NavMesh Plus**로 2D 환경에서도 자연스러운 경로 탐색 구현
- 캐릭터가 장애물을 피해 이동하며 **AI의 지능적 행동**과 **현실감 있는 탐험 경험** 제공

---

### 🧠 Finite State Machine (FSM)
- 캐릭터 행동을 `Idle`, `Move`, `Attack`, `Hit` 등으로 세분화
- 상태 전이 조건을 명확히 정의해 유지보수성과 확장성을 높임
- 새로운 행동 추가 시 기존 코드에 최소한의 영향만으로 기능 확장 가능

---

### 🌐 서버 : ASP.NET Core
- **빠른 성능**
  - 대규모 요청 처리에 강하며, Unity와의 연동이 용이
- **보안 강화**
  - OAuth, JWT 기반 인증 및 암호화
- **높은 확장성**
  - Docker, Kubernetes, Azure 등 클라우드 환경 대응
- **RESTful API 지원**
  - MVC 기반으로 가볍고 효율적인 서버 구조 구성 가능
